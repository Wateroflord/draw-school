# Уроки рисования

Линии, круги, штриховка, объём, свет и тень, перспектива, лицо и фигура, цвет, пиксель-арт и анимация. Упражнения на обводку с оценкой точности, задание дня и наброски на время.

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через Winter Hub, либо скачать файл из раздела **Releases**: `Draw-School.apk` для телефона, `Draw-School-Setup.exe` для ПК.

## Как устроено

Flutter (Dart). lib/course.dart — уроки и упражнения, lib/shapes.dart — фигуры для обводки.

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), сборка APK и установщика для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`) и публикация в Releases.
